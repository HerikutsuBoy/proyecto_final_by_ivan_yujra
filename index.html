Requisitos técnicos mínimos

  • HTML semántico: header, nav, main, section, footer; formularios con label y ayudas.
  • CSS propio con colores coherentes, tablas, botones y media query para celular.
  • JavaScript externo (script.js) con más de 4 funciones y addEventListener.
  • Actualización del DOM sin recargar la página.
  • Arreglos: mantenimiento (objetos), sensores (objetos) y viento (números).
  • Altas, visualización y eliminación de registros.
  • Expresión regular real: /^SEN-\d{3}$/.
  • Validación de rangos, vacíos y valores no numéricos, con mensajes claros.
  • Opcional: localStorage para conservar registros al recargar.
